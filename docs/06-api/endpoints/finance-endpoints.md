# 📊 API Endpoints: Keuangan & Akuntansi

Kumpulan endpoint pengelolaan bagan akun, jurnal umum, dan laporan keuangan.

---

## 1. GET `/api/v1/finance/accounts`
- **Deskripsi**: Daftar bagan akun (*Chart of Accounts*) milik merchant.

---

## 2. GET `/api/v1/finance/journals`
- **Deskripsi**: Daftar entri jurnal pembukuan berpasangan dengan filter rentang tanggal.

---

## 3. GET `/api/v1/finance/reports/z-report`
- **Deskripsi**: Laporan rekap harian shift kasir per outlet.
