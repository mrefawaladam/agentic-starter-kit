# 👤 User Stories: FEAT-HRIS-001 (Payroll to General Ledger)

## US-HRIS-001: Pembukuan Beban Gaji Otomatis
**Sebagai seorang** Admin Keuangan (Finance) & Owner,  
**Saya ingin** saat gaji bulanan seluruh staf dibayarkan, sistem otomatis membukukan beban gaji dan pengeluaran kas ke dalam laporan laba rugi dan buku besar,  
**Sehingga** saya tidak perlu menginput transaksi jurnal umum secara manual dan laporan keuangan bulanan langsung tersaji akurat.

---

## US-HRIS-002: Pemotongan Kasbon Staf yang Tertib
**Sebagai seorang** Admin Keuangan,  
**Saya ingin** pemotongan cicilan kasbon staf saat gajian langsung mengurangi saldo buku piutang karyawan,  
**Sehingga** tidak ada kasbon staf yang lupa ditagihkan atau tercatat ganda.
