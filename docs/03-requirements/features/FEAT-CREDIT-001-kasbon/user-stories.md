# 👤 User Stories: FEAT-CREDIT-001

## US-CREDIT-001: Pengajuan Kasbon Terkontrol
**Sebagai seorang** Kasir Toko,  
**Saya ingin** membuat transaksi kasbon bagi pelanggan terdaftar dengan pengecekan credit limit otomatis,  
**Sehingga** koperasi terlindungi dari risiko piutang macet tanpa memperlambat alur pelayanan.

---

## US-CREDIT-002: Perjanjian Tertulis untuk Kasbon Besar
**Sebagai seorang** Pengurus Koperasi,  
**Saya ingin** setiap kasbon bernilai di atas Rp100.000 wajib dilengkapi surat perjanjian bertanda tangan,  
**Sehingga** koperasi memiliki dasar hukum perdata yang kuat saat melakukan penagihan.

---

## US-CREDIT-003: Pembayaran Cicilan yang Fleksibel
**Sebagai seorang** Anggota / Petani,  
**Saya ingin** mencicil pembayaran kasbon saya secara bertahap atau sekaligus saat panen tiba,  
**Sehingga** kewajiban saya berkurang secara transparan dengan bukti tanda terima resmi.
