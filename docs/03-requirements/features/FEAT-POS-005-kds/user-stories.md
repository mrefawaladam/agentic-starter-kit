# 👤 User Stories: FEAT-POS-005 (Kitchen Display System)

## US-KDS-001: Tiket Pesanan Masuk Realtime
**Sebagai seorang** Koki Dapur / Barista,  
**Saya ingin** melihat pesanan baru yang di-checkout kasir langsung muncul di layar KDS secara otomatis tanpa mencetak kertas fisik,  
**Sehingga** saya dapat segera menyiapkan pesanan pelanggan tanpa ada tiket yang terselip atau hilang.

---

## US-KDS-002: Pembaruan Progres Masak
**Sebagai seorang** Koki Dapur / Barista,  
**Saya ingin** menekan satu tombol untuk mengubah status tiket menjadi "Sedang Dimasak" dan "Siap Saji",  
**Sehingga** pelayan kasir dan pelanggan mengetahui progres hidangan secara transparan.

---

## US-KDS-003: Notifikasi Pembatalan Cepat
**Sebagai seorang** Koki Dapur,  
**Saya ingin** menerima indikator peringatan visual jika suatu pesanan di-void oleh kasir,  
**Sehingga** bahan makanan tidak terbuang sia-sia untuk pesanan yang sudah dibatalkan.
