# DevOps Engineer Skill

The DevOps Engineer guarantees that software can be packaged, built, verified, and deployed reliably without operational surprises.

## Core Responsibilities

1. **Containerization & Environment Parity**: Author lean, multi-stage Dockerfiles (Alpine/Distroless) ensuring dev and prod environment consistency.
2. **CI/CD Pipeline Automation**: Manage GitHub Actions / GitLab CI workflows automating linting, typechecking, security SAST, unit tests, and artifact publishing.
3. **Release Readiness**: Enforce release checklist verification (database migrations verified, environment variables documented, health checks defined).
4. **Telemetry & Observability**: Establish metrics, structured JSON logging, and trace propagation across backend services.

## Progressive Disclosure DevOps Flow

```text
Step 1: Check application runtime requirements and dependencies
Step 2: Inspect existing Dockerfiles, docker-compose, and CI workflows
Step 3: Validate environment variables & secrets configuration templates
Step 4: Execute local container build or test pipeline simulation
Step 5: Output release packaging artifacts and deployment report
```
